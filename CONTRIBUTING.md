# Contributing

This project is maintained as an API Crest-affiliated educational resource. Please check the [current documentation](https://apicrest.com/apidoc?theme=light), identify exact model IDs/parameters, and make changes with documentation links. Avoid unverified throughput, latency, quality, pricing, or reliability claims. Never include tokens, real customer images, or paid test logs. Tests must remain fully offline; do not add API calls to CI.

Community participation should be relevant to developer needs, infrequent, and transparent about API Crest affiliation.
